# Data partitioning and generalization in deep learning-based wildfire detection

Materials for the paper "Data Partitioning and Generalization in Deep Learning-Based Wildfire
Detection: Controlled Experiments and a Reporting Audit" (M. N. A. Ramadan, H. Saygın,
R. Alhindawi, M. Alkhedher; under review). The release lets a reader check every number in the
paper: the controlled partition experiment and the audit of published wildfire detection studies.

## Contents

| Folder | What it holds |
|---|---|
| `protocol/` | The protocol, coding instrument and eligible frame, each frozen with a checksum before the work it governs. |
| `experiment/` | The split definitions for the five allocation rules, the Pyro-SDIS image manifest, every training run's scores and training curves, and the derived estimands. |
| `audit/` | Harvested metadata (abstracts removed), scope decisions, both coders' raw independent codings, agreement and reliability tables, the full-text validation record, the sensitivity matrix and the FLAME timeline. |
| `code/` | The harvesting, screening, coding, analysis, experiment and figure scripts. |
| `supplementary_material.md` | The paper's supplementary material, including the search strings. |

The raw codings in `audit/raw_coding/` are the coders' outputs exactly as produced, before any
agreement analysis or adjudication. They carry short verbatim quotations from the audited papers,
recorded in the language each paper was written in, as the evidence for each code.

## Not included

- Images. The experiment uses Pyro-SDIS, a public dataset of fire-lookout camera images:
  https://huggingface.co/datasets/pyronear/pyro-sdis. `experiment/split_manifest.json` and
  `experiment/pyrosdis_partitions.json` assign every image to a partition.
- Full texts, full-text excerpts and abstracts of the audited papers, which remain under their
  publishers' copyright. Each paper is identified by DOI or OpenAlex ID.
- Model checkpoints and per-image predictions (about 4.8 GB). They are regenerated by
  `code/run_experiment.py` from the frozen hyperparameters and seeds.

## Running the code

The scripts were run from the project root, where the files now in `protocol/`, `audit/` and
`experiment/` sat together in a `corpus/` folder and the scripts in `scripts/`. To re-run one,
recreate that layout. Scripts that query OpenAlex, Crossref or Unpaywall need your own contact
e-mail in place of `your-email@example.org`. `code/runpod_setup.sh` and `code/runpod_run.sh`
reproduce the GPU training environment.
